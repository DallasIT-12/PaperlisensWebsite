# Paperlisens - Official Website & Food Packaging Marketplace

Paperlisens adalah website resmi dan marketplace kemasan makanan & paper tray food grade terpercaya di Indonesia. Dibuat menggunakan Next.js App Router, Tailwind CSS, Supabase, Midtrans Payment Gateway, dan Biteship Logistics API.

## 🚀 Fitur Utama
- **Katalog Produk Dinamis**: Menampilkan ratusan produk & varian kemasan langsung dari Supabase.
- **Kategori & Filter**: Navigasi kategori (Box Cupcake, Paper Tray, Box Take Away, Dus Bakery, Box Nasi).
- **Detail Produk Interaktif**: Image viewer, variant selector, rekomendasi produk cerdas.
- **Checkout & Midtrans**: Integrasi pembayaran otomatis (QRIS, VA Transfer, Minimarket, COD lokal).
- **Cek Ongkir Otomatis**: Integrasi kurir Biteship & diskon ongkir otomatis.
- **SEO & Google Indexing**: Sitemap dinamis (`/sitemap.xml`), robots.txt, dan Schema.org JSON-LD (Product, Breadcrumbs, Organization).
- **Responsive & Mobile Optimized**: Dirancang optimal untuk tampilan smartphone (iOS/Android) dan desktop.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase, NextAuth.js
- **Payment**: Midtrans Snap API
- **Logistics**: Biteship Shipping API
- **Deployment**: Vercel
